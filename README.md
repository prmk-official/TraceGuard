
# TraceGuard

A graph-backed AI security investigator using OWASP Juice Shop evidence.

## Goals
- Graph-based security investigation
- Retrieval-Augmented Generation (RAG)
- Agentic reasoning and tool use
- Persistent investigation history
- Evaluation against a document-only baseline

## Dataset
OWASP Juice Shop — https://github.com/juice-shop/juice-shop
